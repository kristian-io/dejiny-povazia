# Data files

All content on the site comes from these files; `site/build.py` inlines them into the page.

- **Language:** the site is Slovak by default with an English toggle. Every text a visitor reads is an object `{ "sk": "…", "en": "…" }`.
- **Years** are integers (negative = BC).
- **Coordinates** are `[longitude, latitude]` (GeoJSON order).
- **Sources** are IDs from [../sources/sources.md](../sources/sources.md) (`S001…` texts, `M001…` maps and data).
- **Period IDs** look like `p08-early-hungary`; places use short IDs: `sala`, `galanta`, `matuskovo`, `sladkovicovo`.

## periods.json – the 17 stops on the timeline
```json
{
  "id": "p08-early-hungary", "order": 8, "start": 900, "end": 1241,
  "map": "drawn | survey3 | topo25 | zm50",
  "researched": true,
  "label": { "sk": "Uhorské kráľovstvo", "en": "Kingdom of Hungary" },
  "title": { "sk": "…", "en": "…" },
  "summary": { "sk": "…", "en": "…" },
  "ruler": { "state": {"sk","en"}, "county": {"sk","en"}, "local": {"sk","en"} },
  "names": { "sala": "Sala", "galanta": "Galantha", "matuskovo": "Toscun" }
}
```
`map` picks the background: our drawn reconstruction or one of the ZBGIS map images in `site/maps/`. `names` are the town names used in that period.

## events.json – what happened
```json
{
  "id": "e-roman-village-galanta", "period": "p05-romans-quadi",
  "date": { "year": 300, "approx": true },
  "title": { "sk": "…", "en": "…" }, "text": { "sk": "…", "en": "…" },
  "place": "galanta", "coords": [17.7264, 48.1889],
  "confidence": "confirmed | likely | uncertain",
  "sources": ["S031"]
}
```

## places.json – the towns
```json
{
  "id": "sala",
  "names": { "sk": "Šaľa", "hu": "Vágsellye", "de": "Schelle", "historical": ["Sala (c. 1105–1110)", "…"] },
  "coords": [17.8739, 48.1528],
  "firstMention": { "year": 1002, "source": "S004", "note": "…" },
  "county": "Nitra (Nyitra), Vágsellye district",
  "role": "core | context"
}
```

## population.json – census results
`{ "_note": "…", "sala": [ { "year": 1880, "total": 3049, "hu": 707, "sk": 1995 }, … ], … }` – by declared nationality or mother tongue, one series per town.

## layers.json – the drawn map (generated, ODbL)
Made by `site/tools/build_layers.py` from OpenStreetMap and elevation data, in the page's map frame (pixels). Keys: `rivers`, `water`, `wetlands`, `floodplain`, `upland`, `county`, `countyLabels`, `villages` (`{ sk, hu, first, core, coords }`) and `sites` (archaeological sites: `{ id, periods, coords, label, approx, sources }`).

## images.json – pictures
```json
{
  "id": "p08-diakovce-portal", "period": "p08-early-hungary",
  "kind": "photo | building | find | portrait | reconstruction | ai",
  "dated": 1938, "cover": true, "event": "e-…", "place": "diakovce",
  "coords": [17.8469, 48.1343], "approx": false,
  "commons": "Deáki templomkapu 1.JPG",
  "caption": { "sk": "…", "en": "…" },
  "credit": { "author": "Taz666", "license": "CC BY-SA 3.0", "licenseUrl": "…", "url": "…", "site": "Wikimedia Commons" },
  "size": [1200, 1600]
}
```
`commons` or `fortepan` names the source file; `site/tools/fetch_images.py` downloads it to `site/img/<id>.jpg` (+ `_t.jpg` thumbnail). AI pictures (`kind: "ai"`) are made by `site/tools/aigen.py` from **ai_prompts.json** (`{ id, period, cover, event, prompt, caption }`).

## voices.json – "Hlas doby" cards
```json
{
  "id": "v-valyi", "period": "p11-18th-century", "kind": "quote | story",
  "who": {"sk","en"}, "role": {"sk","en"}, "when": "1796",
  "orig": { "lang": "hu", "text": "…" },
  "text": { "sk": "…", "en": "…" },
  "source": { "label": "…", "url": "…" },
  "img": "p14-memorial"
}
```
Only real, sourced voices: short attributed quotes or a paraphrase with a link. `orig` and `img` are optional.

## terms.json and wiki.json – Wikipedia links
**terms.json:** `{ "id": "neanderthal", "wiki": "Neanderthal", "sk": ["neandertál\\p{L}*"], "en": ["Neanderthals?"], "skwiki": "…" }` – regular expressions that find the term in the text; `wiki` is the English article, `skwiki` an optional fixed Slovak article.
**wiki.json** (generated by `site/tools/fetch_wiki.py`, CC BY-SA): per term the Slovak (or Czech) and English preview `{ lang, title, extract, url }`, plus `img` and `imgCredit`.
